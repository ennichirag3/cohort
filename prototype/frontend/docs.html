API REFERENCE · VERSION 1.0

CodeInsight API

Endpoints used by the Evidence Engine and Graph Explorer. Try them here while the backend is running.

Open the machine-readable API schema

Local setup: start FastAPI from prototype/backend with python -m uvicorn main:app --reload. Neo4j features need NEO4J_URI, NEO4J_USERNAME, and NEO4J_PASSWORD in prototype/backend/.env. For public GitHub imports, GITHUB_TOKEN is optional; add a fine-grained, read-only token there if you hit GitHub's unauthenticated rate limit. Keep .env private and out of Git.
GET/

Confirms the API is responding.

{
  "message": "Welcome to CodeInsight API",
  "status": "active"
}

    


    

      
GET/health

      
Checks that the FastAPI process is responding. This check does not verify the Neo4j connection.

      
{ "status": "healthy" }

      
      

    


    

      
POST/api/repositories

      
Fetches a bounded sample of recent history from a public GitHub repository and imports it into Neo4j. Enter the repository URL or its owner/repo name. Public imports need no token, though GitHub may rate-limit repeated unauthenticated requests.

      
Example request (replace owner/repo with the public repository you want to import)

      
{ "repository": "owner/repo" }

      
Example successful response (record counts vary)

      
{
  "status": "imported",
  "repository": "owner/repo",
  "counts": { "commits": 20, "pull_requests": 10, "issues": 15 },
  "message": "Imported recent public history for owner/repo into Neo4j."
}

      
Each import requests up to 20 commits, 10 merged pull requests, and 15 issues; GitHub may return fewer. This API reference shows examples, not live import status. Check the success message on the Evidence Engine; after a successful import, Graph Explorer focuses on that repository. An unsuccessful import does not change the selected graph.

    


    

      
POST/api/ask

      
Searches imported commit, pull request, and issue text for matching words. The Evidence Engine limits searches to the most recently imported repository; API requests can pass an optional repository field (owner/repo). If it is omitted, evidence is searched across all imported repositories. For best results, use a distinctive word from a commit, PR, or issue.

      
Request body

      
{ "question": "empty string", "repository": "pallets/click" }

      
Response shape

      
{
  "answer": "I found 2 matching record(s) in the Neo4j graph. Review the sources for the supporting evidence.",
  "sources": [
    { "type": "Commit", "title": "Example commit message", "url": "https://github.com/...", "excerpt": "Example evidence" }
  ]
}

      
      
      
      

    


    

      
GET/api/graph?q={optional text}

      
Returns up to 100 Neo4j relationships as nodes and edges. Add ?q=psf%2Frequests to filter for one repository and its related history, or use another text fragment to filter matching nodes. Graph Explorer uses the most recently imported repository after a successful import.

      
{
  "status": "connected",
  "nodes": [
    { "id": "node-id", "label": "Commit message", "type": "Commit", "details": { "id": "full-id", "text": "...", "author": "...", "date": "...", "url": "...", "path": "..." } }
  ],
  "edges": [ { "source": "node-id", "target": "other-node-id", "relation": "HAS_COMMIT" } ]
}

      

        
        
      

      

    


    
Common errors: 422 means the request is invalid; 502 means GitHub rejected the fetch (including rate limits); 503 means Neo4j could not be reached; 504 means GitHub took too long. If GitHub rate-limits a public import, wait for its limit to reset or configure optional GITHUB_TOKEN in the ignored backend .env file, then restart FastAPI.
